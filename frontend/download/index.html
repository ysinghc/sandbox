Version 0.12.0. Staged install trees for Linux x86_64 and aarch64, with SHA-256 checksums.

Released 17 October 2026 License GPL-2.0-only Source github.com/ysinghc/sandbox

Before you install.

  • Linux on x86_64 or aarch64, with /dev/kvm.
  • userfaultfd available to the daemon.
  • Root, for taps, device nodes, cgroups, and jails.
  • A Firecracker binary, guest kernel, and rootfs.

Host preparation, install layout, and systemd hardening are covered in the deployment guide.

Install

01

Download and verify

Put the tarball and its checksum in the same directory, then run the check. It should end in OK.

terminal 
$ sha256sum -c sandbox-engine-0.12.0-linux-x86_64.tar.gz.sha256
02

Extract the staged tree

The archive mirrors the filesystem. Extracting it over / places binaries in /usr/local, config in /etc/sandbox-engine, and state in /var/lib/sandbox-engine.

terminal 
$ sudo tar -xzf sandbox-engine-0.12.0-linux-x86_64.tar.gz -C /
03

Stamp a template, then start

The packaged unit runs the daemon. A template has to be stamped once on the host before the first create; the helper lives in the source tree.

terminal 
# from the source checkout
$ sudo -E env SANDBOX_SNAPSHOT_ROOT=/var/lib/sandbox-engine/snapshots \
    SANDBOX_JAIL_ROOT=/var/lib/sandbox-engine/jail \
    build/tests/make_template

$ sudo systemctl enable --now sandboxd
$ sudo sandbox-cli verify --template e2e

Build from source

The release tarballs are built from the tagged source with the same CMake project. If you need a different install prefix, a sanitizer build, or the fuzzers, build it yourself:

terminal 
$ git clone https://github.com/ysinghc/sandbox.git
$ cd sandbox
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j
$ sudo cmake --install build

Dependencies, build options, and the sanitizer targets are in the building guide. Older versions are on the releases page.
