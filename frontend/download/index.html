Version 0.13.0. Install with one script, or take the archive for your architecture. Both are checksummed.

Released 20 October 2026 License GPL-2.0-only Source github.com/ysinghc/sandbox

Before you install.

  • Linux on x86_64 or aarch64, with /dev/kvm.
  • userfaultfd available to the daemon.
  • Root, for the installer, taps, cgroups, and jails.
  • curl and tar for the install script.
  • A Firecracker binary, guest kernel, and rootfs.

Host preparation, install layout, and systemd hardening are covered in the deployment guide.

One-command install

scripts/install.sh detects the machine's architecture, downloads the matching release, verifies its SHA-256, and installs the binaries and libraries. Read it first; it is a short shell script.

terminal 
# inspect, then install the full staged tree over /
$ curl -fsSL -o install.sh \
    https://raw.githubusercontent.com/ysinghc/sandbox/v0.13.0/scripts/install.sh
$ less install.sh
$ sudo bash install.sh --version v0.13.0 --full

# or install just the binaries and libraries into /usr/local
$ sudo bash install.sh --version v0.13.0

# useful options
$ bash install.sh --prefix /opt/sandbox
$ bash install.sh --dry-run

What --full adds

The staged tree includes the systemd unit, packaged config, and state directories. Without --full, only sandboxd, sandbox-broker, sandbox-cli, and the two client libraries are installed.

Manual install

01

Download and verify

Put the tarball and its checksum in the same directory, then run the check. It should end in OK.

terminal 
$ sha256sum -c sandbox-engine-0.13.0-linux-x86_64.tar.gz.sha256
02

Extract the staged tree

The archive mirrors the filesystem. Extracting it over / places binaries in /usr/local, config in /etc/sandbox-engine, and state in /var/lib/sandbox-engine.

terminal 
$ sudo tar -xzf sandbox-engine-0.13.0-linux-x86_64.tar.gz -C /
03

Stamp a template, then start

The packaged unit runs the daemon. A template has to be stamped once on the host before the first create; the helper lives in the source tree.

terminal 
# from the source checkout
$ sudo -E env SANDBOX_SNAPSHOT_ROOT=/var/lib/sandbox-engine/snapshots \
    SANDBOX_JAIL_ROOT=/var/lib/sandbox-engine/jail \
    build/tests/make_template

$ sudo systemctl enable --now sandboxd
$ sudo sandbox-cli verify --template e2e

Build from source

The release tarballs are built from the tagged source with the same CMake project. If you need a different install prefix, a sanitizer build, or the fuzzers, build it yourself:

terminal 
$ git clone https://github.com/ysinghc/sandbox.git
$ cd sandbox
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j
$ sudo cmake --install build

Dependencies, build options, and the sanitizer targets are in the building guide. Older versions are on the releases page.
